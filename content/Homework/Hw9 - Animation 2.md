# Group Work

**Project Managers**: For group work this week, you will refine the blocking animation for your short. Your group will add more to the initial blocking to achieve the principles of animation and improve the quality of your animation. We recommend sticking to the same assigned shots you did when blocking.

 If you would like to improve the skinning of your rigs as well, make sure to update the referenced rig file so that it propagates across all animated shots using the rig.


> [!warning] DO NOT KEY THE MASTER CONTROLLER
> **Never keyframe the master controller!** Recall that the master controller is the highest controller in the hierarchy. The purpose of the master controller is to allow you to move the whole animation in case something needs to be adjusted. **Movement should be done using other controllers, such as the Center of Gravity (CoG) controller**.
